# مترجم الشاشة — Screen Translator

برنامج صغير جداً لويندوز 11 (حوالي 80 كيلوبايت). بتضغط **Ctrl + Alt + T**، بتحدد أي منطقة على الشاشة بالماوس، والنص الإنجليزي اللي فيها بيتبدّل بترجمته العربية **فوق النص الأصلي، بنفس مكانه**.

بيشتغل على أي إشي على الشاشة: مواقع، PDF، برامج، صور، ألعاب...

## التنزيل والتشغيل

1. افتح صفحة **Releases** بالريبو ونزّل `ScreenTranslator.exe`.
2. حطّه بأي مجلد بدك إياه (مثلاً `Documents\ScreenTranslator`) وشغّله.
3. إذا طلعتلك رسالة **"Windows protected your PC"**: اضغط **More info** ← **Run anyway**. الرسالة بتطلع لأن البرنامج مش موقّع بشهادة مدفوعة، مش لأنه فيه مشكلة.
4. رح تظهر أيقونة البرنامج جنب الساعة (ممكن تكون مخفية تحت السهم ^).

## الاستخدام

| الحركة | الوظيفة |
|---|---|
| `Ctrl + Alt + T` | ابدأ الترجمة وحدّد المنطقة |
| سحب بالماوس | تحديد المنطقة |
| `Esc` أو كليك يمين | إلغاء التحديد |
| كليك على الترجمة أو بأي مكان ثاني أو `Esc` | إغلاق الترجمة |
| `Ctrl + C` على الترجمة | نسخ الترجمة |
| كليك يمين على الترجمة | نسخ الترجمة أو النص الأصلي |
| كليك على أيقونة البرنامج | نفس الاختصار |

**التشغيل مع ويندوز:** كليك يمين على الأيقونة ← فعّل "التشغيل مع ويندوز".

## كيف بيشتغل (ومجاني بالكامل)

- **قراءة النص من الشاشة:** محرك OCR المبني داخل ويندوز. مجاني وبدون إنترنت.
- **الترجمة:** Google Translate (الواجهة المجانية بدون مفتاح)، وإذا وقفت بيستخدم MyMemory كبديل. الترجمة محتاجة إنترنت.
- كل فقرة بتنترجم كوحدة وحدة (مش سطر سطر)، عشان المعنى يضل صحيح، وبتنرسم فوق مكانها الأصلي بنفس لون الخلفية ولون الخط.

## إذا طلعت رسالة إنه قارئ النصوص الإنجليزي مش مثبّت

الإعدادات ← الوقت واللغة ← اللغة والمنطقة ← إضافة لغة ← **English (United States)**.
أو من PowerShell كمسؤول:

```powershell
Add-WindowsCapability -Online -Name "Language.OCR~~~en-US~0.0.1.0"
```

## تغيير اللغات أو الاختصار

كل الإعدادات بملف واحد: `src/ScreenTranslator/Config.cs`. أي تعديل بتعمله وبترفعه، GitHub بيبني نسخة جديدة لحاله وبينشرها بالـ Releases.

## البناء

GitHub Actions بيبني البرنامج على ويندوز مع كل تعديل، وبيعمل اختبار ذاتي (بيقرأ نص إنجليزي من صورة وبيترجمه) قبل ما ينشر النسخة. للبناء يدوياً:

```
dotnet build src/ScreenTranslator/ScreenTranslator.csproj -c Release -o out
```
