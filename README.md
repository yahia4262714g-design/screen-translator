# مترجم الشاشة — Screen Translator

برنامج صغير جداً لويندوز 11 بيترجم أي نص إنجليزي على الشاشة للعربي، وبيساعدك تتعلّم الكلمات وانت عم تقرأ.

## طريقتين للترجمة

| الاختصار | متى تستخدمه | شو بيصير |
|---|---|---|
| **Ctrl + Alt + C** | النص قابل للتظليل (مواقع، PDF، Word، Claude...) | بتظلّل النص وبتضغط الاختصار، فبتطلع بطاقة جنب الماوس فيها الترجمة والنص الأصلي. أسرع وأدق طريقة. |
| **Ctrl + Alt + T** | النص مش قابل للتظليل (صور، فيديو، ألعاب، أزرار) | بتحدد منطقة بالماوس، فبتنحط الترجمة فوق النص الأصلي مكانه. |

## وضع التعلّم

- **ببطاقة النص المحدد:** اضغط على أي كلمة إنجليزية، فبتطلع بطاقة فيها معناها ولفظها، وبتنطق الكلمة لحالها.
- **بترجمة المنطقة:** مرّر الماوس على الترجمة، فبيبيّن النص الإنجليزي الأصلي مكانها. اضغط على أي كلمة فيه لتشوف معناها.
- **ببطاقة الكلمة:** 🔊 بتسمعك اللفظ مرة ثانية، و☆ بتحفظ الكلمة مع الجملة اللي جات فيها.
- **كلماتي المحفوظة:** كليك يمين على أيقونة البرنامج ← "كلماتي المحفوظة". من هناك بتقدر تسمع أي كلمة (دبل كليك)، أو تحذفها، أو تنسخ القائمة كلها.
  الملف محفوظ بـ `%AppData%\ScreenTranslator\words.tsv` وبينفتح بـ Excel.

## التنزيل والتشغيل

1. نزّل `ScreenTranslator.exe` من صفحة **Releases**.
2. حطّه بمجلد ثابت (مثلاً `Documents\ScreenTranslator`) وشغّله.
3. إذا طلعتلك رسالة **"Windows protected your PC"**: اضغط **More info** ← **Run anyway**. الرسالة بتطلع لأن البرنامج مش موقّع بشهادة مدفوعة.
4. رح تظهر أيقونة البرنامج جنب الساعة (ممكن تكون مخفية تحت السهم ^).
5. كليك يمين على الأيقونة ← فعّل **"التشغيل مع ويندوز"** عشان يضل جاهز دايماً.

**للتحديث:** سكّر البرنامج (كليك يمين على الأيقونة ← خروج)، وبدّل الملف القديم بالجديد، وشغّله.

## أوامر سريعة

| بالبطاقة أو بالترجمة | الوظيفة |
|---|---|
| `Esc` أو زر ✕ | سكّر بطاقة الكلمة، وإذا كبستها مرة ثانية بتسكّر الترجمة |
| كليك برّا الترجمة | ما بيصير إشي، الترجمة بتضل ظاهرة لحد ما تسكّرها |
| زر النسخ ⧉ | نسخ الترجمة |
| عجلة الماوس | التمرير بالنصوص الطويلة |
| كليك يمين على ترجمة المنطقة | نسخ الترجمة، نسخ الأصل، استمع للأصل |

## الألعاب والبرامج بوضع ملء الشاشة

- نوافذ البرنامج ما بتاخذ التركيز أبداً، فاللعبة بتضل قدامك وما بتصغّر.
- وانت عم تحدد، الشاشة بتضل حية. بس المنطقة اللي بتحددها هي اللي بتتجمد وبتنحط الترجمة فوقها.
- إذا الترجمة ما ظهرت فوق اللعبة أبداً: غيّر وضع العرض من إعدادات اللعبة لـ **Borderless** أو **Windowed Fullscreen**. وضع **Exclusive Fullscreen** بيمنع أي برنامج يرسم فوق اللعبة.
- وطالما الترجمة ظاهرة، زر `Esc` محجوز لإغلاقها. بعد ما تسكّرها، بيرجع للعبة عادي.

## كيف بيشتغل (ومجاني بالكامل)

- **قراءة النص من الشاشة:** محرك OCR المبني داخل ويندوز (بدون إنترنت).
- **الترجمة ومعاني الكلمات:** Google Translate (الواجهة المجانية)، ومعه MyMemory كبديل.
- **النطق:** صوت Google، وإذا ما في نت بيستخدم صوت ويندوز.
- **الحافظة:** لما تستخدم Ctrl + Alt + C، البرنامج بينسخ النص المظلّل، وبعدها بيرجّع الحافظة زي ما كانت.
- **نصوص الـ PDF:** الأسطر المكسورة بترجع تنضم لجمل كاملة قبل الترجمة.

## إذا طلعت رسالة إنه قارئ النصوص الإنجليزي مش مثبّت

الإعدادات ← الوقت واللغة ← اللغة والمنطقة ← إضافة لغة ← **English (United States)**.
أو من PowerShell كمسؤول:

```powershell
Add-WindowsCapability -Online -Name "Language.OCR~~~en-US~0.0.1.0"
```

## تغيير اللغات أو الاختصارات

كل الإعدادات بملف واحد: `src/ScreenTranslator/Config.cs`. أي تعديل بترفعه، GitHub بيبني نسخة جديدة لحاله وبينشرها بالـ Releases.

## البناء والاختبار

مع كل تعديل، GitHub Actions بيبني البرنامج على ويندوز وبيعمل اختبار ذاتي: قراءة النص، الترجمة، القاموس، وتنظيف نصوص الـ PDF. وكمان بيرسم صور للواجهة وبينشرها بإصدار **ui-preview**. للبناء يدوياً:

```
dotnet build src/ScreenTranslator/ScreenTranslator.csproj -c Release -o out
```
